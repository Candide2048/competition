# 双碳大赛_风帆推进碳减排

## 项目信息

- **比赛：** 第四届中国研究生"双碳"创新与创意大赛
- **赛道：** 赛道五 命题26——双碳战略与智能交通
- **项目：** 面向航运碳中和的风帆辅助推进智能效益预测与航线适配决策系统

## 文件夹结构

```
双碳大赛_风帆推进碳减排/
├── README.md                    ← 本文件
├── 创新计划书_框架.md            ← 计划书完整框架（已按比赛要求格式）
├── 数据/                        ← 待建：ERA5数据、航线数据等
├── 代码/                        ← 待建：Python代码
├── 结果/                        ← 待建：分析结果、图表
└── 参考文献/                    ← 待建：论文、报告
```

## 技术栈

- **语言：** Python
- **气象数据处理：** xarray, netCDF4, cfgrib
- **数据分析：** pandas, numpy, scipy
- **可视化：** matplotlib, seaborn, folium（交互式地图）
- **风帆推力计算：** 自建模型（基于公开空气动力学公式）
